# EC02 - Gestão de Funcionários

Sistema em HTML e JavaScript para cadastrar, listar, alterar e excluir funcionários, com relatórios.

- **Exercício 1:** formulário (nome, idade, cargo, salário), classe `Funcionario` com get/set e `toString()`, tabela.
- **Exercício 2:** botões Excluir e Editar; edição carrega no formulário e atualiza via métodos da classe.
- **Exercício 3:** funções anônimas nos eventos e arrow functions para buscar, remover e atualizar no array.
- **Exercício 4:** relatórios com `filter`, `map`, `reduce` e `new Set()`.

## Como rodar com Docker

```bash
docker compose up --build
```

Acesse http://localhost:8081
